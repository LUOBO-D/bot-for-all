# 设计令牌与使用规范（v2）

来源：`frontend/src/styles/tokens.css`（唯一事实源）
适用范围：`frontend/src/**`

> 规则：组件样式只允许引用变量，不允许写死色值/字号/间距/时长。新增令牌必须同步登记到本文档。

## 1. 色彩

### 1.1 中性阶（深海）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#04070f` | 最深底色、正文按钮上的文字 |
| `--ink-2` | `#0a1222` | 次级深面 |
| `--ink-3` | `#101b30` | 深面高亮 |
| `--paper` | `#050a15` | 页面底色 |
| `--paper-2` | `#0b1424` | 抬升面（卡片/气泡） |
| `--paper-3` | `#0e1a2e` | 凹陷面（输入框/阱） |
| `--white` | `#f4faff` | 纯白文字备用 |

### 1.2 线

| 令牌 | 值 | 用途 |
|---|---|---|
| `--line` | `rgba(120,180,255,.10)` | 默认分隔线、卡片描边 |
| `--line-strong` | `rgba(120,180,255,.22)` | 可交互元素描边 |
| `--line-on-ink` | `rgba(180,220,255,.12)` | 深面上的分隔线 |

### 1.3 文字

| 令牌 | 值 | 对比度（对 `--paper`） |
|---|---|---|
| `--text` | `#e6f0ff` | 约 15.8:1 |
| `--muted` | `#a5b8d4` | 约 9.4:1 |
| `--faint` | `#7e90ac` | 约 5.6:1（仅用于 ≥11px 辅助信息） |

### 1.4 主色（仅三组，禁止新增）

| 令牌 | 值 | 语义 | 约束 |
|---|---|---|---|
| `--lime` / `-hover` / `-active` | `#48e6c5` / `#6cf2d7` / `#2fd3b2` | 人类交互、选中、在线、主按钮 | 作为填充时文字必须用 `--ink`；禁止作为 12px 以下正文色 |
| `--rust` / `--rust-ink` | `#ff8f5e` / `#ffb088` | **机器人专属**：边框、BOT 标签、流式呼吸 | 不得用于人类消息或通用按钮 |
| `--danger` / `--danger-soft` | `#ff7070` / 12% 填充 | 错误、删除、失败态 | 仅语义使用 |

## 2. 排版

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-display` | 34px（紧凑 30px） | 页面主标题 |
| `--fs-h` | 20px（18px） | 区块标题 |
| `--fs-body` | 15px（14px） | 正文、消息 |
| `--fs-sub` | 13px（12px） | 次级说明 |
| `--fs-mono` | 11px（10px） | 时间、编号、标签（等宽 + 0.2em 字距） |
| `--lh-body` | 1.65（1.55） | 正文行高 |

字体栈：`--font-body` 系统中文栈；`--font-mono` 系统等宽栈。**不引用外部字体 CDN**（离线可用）。

## 3. 间距与形状

- 间距基线 **4px**：`--space-1..10`（4/8/12/16/20/24/32/40）。
- 圆角：`--r-sm 6` / `--r-md 10` / `--r-lg 16` / `--r-xl 22`。
- 阴影仅两级：`--shadow-pop`（浮层）、`--shadow-dialog`（对话框）。
- 触控目标：`--tap: 44px`，所有可点击元素最小高度不得低于此值（图标按钮可用 padding 补足）。

## 4. 材质

| 令牌 | 说明 |
|---|---|
| `--glass` | 常规玻璃面板：渐变 + 1px 冷光描边 + 顶部内高光 |
| `--glass-strong` | 对话框/抽屉，透明度更低、模糊更强 |
| `--glass-border` | 玻璃描边色 |
| `--glow-aqua` / `--glow-coral` | 悬浮态光晕（人类/机器人） |

使用约束：同一屏最多两个玻璃层级（面板 + 浮层）；不允许玻璃套玻璃超过两层。

## 5. 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--dur-instant` | 120ms | 按下反馈、hover 变色 |
| `--dur-fast` | 180ms | 按钮/输入态切换 |
| `--dur-base` | 260ms | 面板入场、路由过渡 |
| `--dur-slow` | 480ms | 大板块入场 |
| `--ease-out` | `cubic-bezier(.2,.8,.2,1)` | 入场、浮起 |
| `--ease-standard` | `cubic-bezier(.4,0,.2,1)` | 状态切换 |

硬约束：
1. 只动画 `transform` 与 `opacity`（玻璃模糊、box-shadow 仅限低频状态变化）。
2. 无限循环动画同时最多 2 个（环境光 + 鲸鱼），且周期 ≥14s。
3. `prefers-reduced-motion: reduce` 下全部动画降至 0.001ms。

## 6. 密度模式

| 模式 | 触发 | 差异 |
|---|---|---|
| `comfort`（默认） | 大学生/阅读优先 | 15px 正文、消息间距 9px、卡片 18px 内边距 |
| `compact` | 科研/信息密度优先 | 14px 正文、间距 5px、卡片 12px 内边距、顶栏更薄 |

实现：`:root[data-density='compact']` 覆盖令牌；切换入口在侧栏「显示密度」，持久化到 `localStorage['bfa-density']`。

## 7. 状态清单（组件必须有）

| 状态 | 表现要求 |
|---|---|
| 空 | 说明 + 下一步动作，禁止只显示"暂无数据" |
| 加载 | 骨架或进度提示，禁止布局跳动（CLS 0） |
| 错误 | 说明 + 重试路径，禁止吞错 |
| 离线 | 顶部横幅 + 立即重连按钮 |
| 流式 | 呼吸光晕 + 光标，禁止突然整段出现 |
| 长内容 | 折叠 + 展开全文，蒙版淡出而非硬裁切 |
| 无权限 | 明示原因，禁用而非隐藏关键操作 |

## 8. 禁止事项

- 禁止在组件内写死 `#hex`、`px` 字号、`ms` 时长（调试态可临时，提交前改回令牌）。
- 禁止新增第四主色；禁止用机器人珊瑚橙表达人类状态。
- 禁止用 `filter: blur()` 做常规文字效果（性能与可读性双输）。
- 禁止用 emoji 充当图标（`Icon.vue` 已有线性图标集）。
